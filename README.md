# Mesa de Desenho Geométrico — Régua e Compasso

Aplicativo web de desenho geométrico com régua, compasso, esquadros, transferidor, lápis, borracha, camadas e exportação PNG.

## Executar

Abra [a Mesa de Desenho Geométrico](https://pedroromaobatista.github.io/mesa-desenho-geometrico/).

## Arquivos

- `index.html`: aplicativo completo.
- `texturas/`: cinco imagens de fundo da folha, referenciadas localmente pelo aplicativo.

Para publicar no GitHub Pages, mantenha `index.html` e a pasta `texturas` na raiz do repositório.
